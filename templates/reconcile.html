What this does — and does not — prove
  • Synthetic data. Every figure is measured on one seeded synthetic dataset; it is illustrative of the method, not a real-world benchmark or a claim of state-of-the-art performance.
  • Internal consistency, not correctness. This proves the engines agree with each other and with the docs to the cent (or the reported %); it does not validate the underlying models against real demand, prices or routes.
  • The README guard works at display precision. A figure the README rounds (e.g. MASE to two decimals) is checked at that precision; the identity checks and the CSV value column carry the engines' full precision.
  • Deterministic. The dataset is seeded and every engine terminates on a fixed seed / solution budget (never a wall clock), so this ledger is byte-identical on every run — regenerate the full report with python -m dip --reconcile.
